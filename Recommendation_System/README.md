This project builds a product recommendation system using customer transaction data. It recommends similar products based on user purchase behavior.

🚀 Features



Data cleaning and preprocessing

Customer-item matrix creation

Binary transformation

Cosine similarity for item-item recommendation

Top-N product recommendations

🧠 Approach

Clean dataset (remove nulls, invalid values)

Create customer-item matrix

Convert to binary format

Compute cosine similarity

Recommend top similar products

🛠 Tech Stack

Python

Pandas

NumPy

Scikit-learn
